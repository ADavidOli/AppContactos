# Gestor de contactos  - Frontend

> **Mi bitacora de aprendizaje** Este README documenta desde el inicio del proyecto la parte frontend y porque organice el codigo de la siguiente manera, utilizando vite-React y tailwind para la parte del diseño


## Instalacion y configuracion desde la creacion del proyecto

Estos pasos sirven para **recrear el frontend desde cero**, no solamente para ejecutar una copia descargada.

### iniciar el proyecto

nos pasamos a la carpeta raíz del proyecto y ahí mismo ejecutamos.

```bash
  cd /appContactos
  npm create vite@latest frontend -- --template react-ts
```
seleccionamos ESlint para despues ejecutar

```bash
  cd frontend
  npm install
  npm install axios
  npm install tailwindcss @tailwindcss/vite  
  npm run dev
```
